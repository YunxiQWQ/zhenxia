# 帧匣 Zhenxia v0.2.4

此版本汇总 v0.2.1 之后的剪贴板、图片与窗口修正。

## 更新内容

- 剪贴板历史采用 480×580 紧凑面板和 Cubby 风格顶部；记录旁按钮直接粘贴，点击内容打开详情。精简常驻快捷键说明和重复按钮，中文相对时间跟随语言。
- 快捷键录入按物理键处理，支持中文输入法下的 Ctrl+·；保留冲突检测和原绑定恢复。
- 接通扫一扫：截图工具栏、工具菜单、托盘、历史图片详情、编辑器及独立全局热键。二维码离线识别，无需模型；结果链接不会自动打开。
- 截图工具栏支持拖动排序，以及在显示区和隐藏区之间双向拖动；默认图片查看器使用 Windows 关联，可选自定义程序。
- 统一历史、设置、翻译、截图/编辑器、图片查看、贴图、长截图/录屏控制及演示画布的窗口边框，移除额外系统标题栏及最大/最小按钮，保留窗口材质与圆角。修正标题拖动坐标导致的跳位。
- 长截图和录屏从截图选区连续交接，避免先取消截图、提前弹回设置页而遮挡源页面；取消或编辑结束后恢复原设置页。控制窗在有空间时避开选区。
- 长截图支持显式自动滚动、离区/切换窗口暂停、匹配失败保留已有结果及连续无变化暂停。
- 录屏取帧接入 MIT 许可的 windows-capture 2.0.1，优先使用 Windows Graphics Capture；不可用时使用兼容路径。MP4 默认目标 30 FPS，GIF 默认 12 FPS。

## 下载和升级

- 安装版：`Zhenxia-0.2.4-windows-x64-setup.exe`。同一安装版原位升级保留历史、设置及已装的离线 OCR/翻译组件，无需重新下载。
- 便携版：`Zhenxia-0.2.4-windows-x64.zip`。退出程序后替换程序文件，保留原来的 `portable.txt` 与 `data`。
- **安装版与便携版之间不支持数据迁移，历史记录不互通。**
- 同时提供对应源码 ZIP 和 `SHA256SUMS.txt`。程序使用系统 WebView2 Runtime，发行包未签名，不捆绑可选模型。

## 验证与边界

Windows 11 x64：前端全量 268 项、原生 584 项通过（2 项原有测量忽略）；最终设置页补丁另跑 12 项，并通过安装版原生鼠标拖动校验。实际窗口/浏览器长截图 40 项、设置圆角/层级 12 项、安装及离线组件 9 项和最终标题拖动 3 项通过。

独立浏览器文档验证了从设置页发起、框选、实际滚动拼接、自动滚轮、进入编辑器和退出恢复。原位升级前后 28 个已安装组件文件校验值一致，PP-OCR small 和中英离线翻译实际运行通过。

长截图仍为向下拼接；复杂动态页面、固定浮层和更多混合 DPI 多屏未全面验证。录屏仍不含音频，实际帧率取决于分辨率和负载。标注导出为扁平图片，深层元素吸附、完整贴图控制及跨会话对象编辑仍有差距。
