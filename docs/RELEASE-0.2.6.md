# 帧匣 Zhenxia v0.2.6

这一版改进了图片较多时的历史加载和分类切换，补上 JPG 导出，并统一图片工具的窗口外观。

## 更新

- Win+V 优先加载首屏记录和视口附近的缩略图，滚动时补载后续记录。切换「全部」「文字」「图片」时，已有匹配项先显示，新结果随后补齐。快速切换时，较早返回的结果不会覆盖当前分类。
- 设置中的截图历史按页批量读取缩略图。日期、尺寸和类别筛选覆盖全部记录，截图和录屏按时间混排。
- 截图、图片编辑、历史图片和贴图的保存窗口均可选择 JPEG（`.jpg` 或 `.jpeg`）。PNG 仍为默认格式。
- 图片编辑器、查看器和长截图／录屏控制窗沿用主窗口的主题、纯色／云母／亚克力和圆角设置。贴图与演示画布的工具栏使用应用主题，透明图像和画布仍可透出桌面。
- 「跟随系统」使用 Windows 的主题状态并接收系统变化通知。编辑器开着时也能同步设置。

## 下载与升级

- 安装版 `Zhenxia-0.2.6-windows-x64-setup.exe` 支持原位升级，保留已有历史、设置和离线 OCR／翻译组件。
- 便携版 `Zhenxia-0.2.6-windows-x64.zip` 解压即可使用。更新前退出旧程序，换上新版程序文件并保留旧的 `portable.txt` 和 `data`。
- 安装版与便携版之间不支持数据迁移。发行包使用系统 WebView2 Runtime，不捆绑可选 OCR 或翻译模型。
- 附带对应源码 ZIP 和 `SHA256SUMS.txt`。

## 验证与许可

Windows 11 x64 下通过前端 274 项、原生 587 项测试。用 600 张合成图片和 80 条文字复查实际历史窗口和分类切换，并通过 Windows 保存窗口选择 JPEG，导出的文件可正常解码。实测了应用的三种主题、三种窗口材质和圆角开关。「跟随系统」按测试电脑当时的 Windows 主题核对。
